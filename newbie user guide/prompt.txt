คุณกำลังทำหน้าที่เป็นผู้ติดตั้ง Pasadu standalone skill แบบ global สำหรับ Codex บน Windows

เป้าหมายคือติดตั้งและตรวจสอบ skill ให้ใช้งานได้จริง ไม่ใช่เพียงแสดงคำสั่งให้ฉันทำเอง

ให้ดำเนินการตามลำดับนี้:

1. อ่าน INSTALLATION.md ฉบับปัจจุบันจาก:
   https://github.com/RobbyGrean/PassaduAIagent/blob/main/INSTALLATION.md
2. ตรวจว่าเป็น Windows ผู้ใช้ไม่จำเป็นต้องมี Node.js, npm หรือ Git และห้ามบังคับให้ติดตั้งเครื่องมือเหล่านี้
3. กำหนดตำแหน่ง global Codex skill เป็น:
   %USERPROFILE%\.agents\skills\pasadu
4. ก่อนเขียนไฟล์ ให้ตรวจว่าตำแหน่งดังกล่าวมีอยู่หรือไม่
5. ถ้ามีอยู่แล้ว:
   - อ่าน SKILL.md ส่วนหัว
   - ถ้าเป็น Pasadu ให้ถือว่างานนี้เป็นการอัปเดตและต้องสร้าง backup ก่อนสลับไฟล์
   - ถ้าไม่สามารถยืนยันว่าเป็น Pasadu ห้ามลบหรือเขียนทับ ให้หยุดและรายงาน
6. ใช้วิธีติดตั้งที่ไม่ต้องพึ่ง Node.js หรือ Git:
   - รันลำดับ PowerShell นี้ทีละขั้นและตรวจ exit status:

     $workPath = Join-Path $env:TEMP ("pasadu-" + [guid]::NewGuid().ToString("N"))
     $zipPath = Join-Path $workPath "pasadu.zip"
     New-Item -ItemType Directory -Path $workPath | Out-Null
     Invoke-WebRequest -Uri "https://github.com/RobbyGrean/PassaduAIagent/archive/refs/heads/main.zip" -OutFile $zipPath
     Expand-Archive -LiteralPath $zipPath -DestinationPath $workPath
     $repoPath = Join-Path $workPath "PassaduAIagent-main"
     $installerPath = Join-Path $repoPath "scripts\install-pasadu.ps1"
     Get-Content $installerPath
     powershell -NoProfile -ExecutionPolicy Bypass -File $installerPath -Agent codex

   - สคริปต์ต้องตรวจ source, ไม่เขียนทับ skill อื่น, และสร้าง backup ก่อนอัปเดต Pasadu เดิม
   - ห้าม pipe สคริปต์จากอินเทอร์เน็ตเข้า shell โดยตรง
7. หากระบบขอสิทธิ์เขียน user-level directory หรือเชื่อมต่ออินเทอร์เน็ต ให้ขอสิทธิ์ตามระบบแล้วดำเนินการต่อเมื่อได้รับอนุญาต
8. ตรวจจาก exact path และไฟล์จริง:
   - %USERPROFILE%\.agents\skills\pasadu\SKILL.md
   - %USERPROFILE%\.agents\skills\pasadu\pasadu.md
   - %USERPROFILE%\.agents\skills\pasadu\reference\law\prb60.md
   - %USERPROFILE%\.agents\skills\pasadu\reference\law\rbb60.md
   - %USERPROFILE%\.agents\skills\pasadu\scripts\pasadu\evidence_packet.py
   - %USERPROFILE%\.agents\skills\pasadu\data\index\chunks.json
   - %USERPROFILE%\.agents\skills\pasadu\data\release.json
9. ห้ามแก้กฎหมาย, index หรือสคริปต์เพื่อทำให้ verification ผ่าน
10. หากคำสั่งใดล้มเหลว ให้รายงานคำสั่ง, exit code และสาเหตุจริง
11. หลังติดตั้งและตรวจไฟล์ทั้งหมดครบเท่านั้น ให้ตอบบรรทัดแรกว่า:

PASADU_INSTALLED

จากนั้นระบุตำแหน่งติดตั้ง และแจ้งให้เริ่ม task ใหม่หรือเปิด Codex ใหม่หาก skill ยังไม่ปรากฏ

อย่าเพิ่งตอบคำถามกฎหมายใน task นี้ งานนี้มีขอบเขตเฉพาะการติดตั้งและตรวจสอบ Pasadu
