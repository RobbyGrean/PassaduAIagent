เริ่มต้นใช้งาน Pasadu

Pasadu คือ standalone AI skill สำหรับงานจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐของไทย

สิ่งที่ต้องมี

1. คอมพิวเตอร์ Windows
2. Codex Windows App หรือ Codex CLI
3. อินเทอร์เน็ต
4. อนุญาตให้ Codex เขียนโฟลเดอร์ skill ของผู้ใช้

ผู้ใช้ทั่วไปไม่ต้องติดตั้ง Node.js, npm หรือ Git

วิธีแนะนำ: ให้ Codex ติดตั้งแทน

1. เปิด task ใหม่ใน Codex
2. เปิด prompt.txt ที่อยู่ในโฟลเดอร์เดียวกับไฟล์นี้
3. คัดลอกข้อความทั้งหมดไปส่งให้ Codex
4. อนุญาตเฉพาะสิทธิ์ที่จำเป็นต่อการดาวน์โหลดและเขียน global skill directory
5. รอจน Codex ตรวจไฟล์ครบและแจ้ง:

PASADU_INSTALLED

Codex จะดาวน์โหลด ZIP ผ่าน HTTPS ด้วย PowerShell ที่มีใน Windows แล้ว copy เฉพาะ standalone skill
ไปยังตำแหน่งที่ถูกต้อง ไม่ต้องติดตั้งเครื่องมือสำหรับนักพัฒนาเพิ่ม

ทางเลือกสำหรับเครื่องที่มี Node.js อยู่แล้ว

Skills CLI ยังใช้ได้:

npx.cmd --yes skills@latest add RobbyGrean/PassaduAIagent --skill pasadu --agent codex --global --copy --yes

การติดตั้งแบบไม่ใช้ Node.js

prompt.txt จะสั่งให้ Codex:

1. ดาวน์โหลด ZIP ของ repository ลงโฟลเดอร์ชั่วคราวด้วย HTTPS
2. อ่าน scripts/install-pasadu.ps1 ก่อนรัน
3. ตรวจว่า source เป็น Pasadu
4. copy เฉพาะ skills/pasadu ไปยัง global path
5. ถ้ามี Pasadu เดิม ให้สร้าง backup ก่อนอัปเดต
6. ตรวจไฟล์จริงหลังติดตั้ง

fallback นี้ไม่ใช้วิธีดาวน์โหลดสคริปต์แล้ว pipe เข้า PowerShell โดยตรง

ตำแหน่งที่ถูกต้อง

%USERPROFILE%\.agents\skills\pasadu

ทดสอบการใช้งาน

ถามตามธรรมชาติ:

การจัดซื้อโดยวิธีเฉพาะเจาะจงใช้ได้เมื่อใด กรุณาอ้างตัวบท

เรียกแบบชัดเจน:

$pasadu มาตรา 56 กล่าวถึงอะไร

Pasadu ยังรองรับข้อความ alias:

/pasadu มาตรา 56 กล่าวถึงอะไร
/passadu มาตรา 56 กล่าวถึงอะไร

หาก UI ไม่ส่ง slash alias ให้ skill ให้ใช้ $pasadu หรือถามตามธรรมชาติ

อัปเดต

วิธีแนะนำคือเปิด task ใหม่ แล้วคัดลอก update-prompt.txt ไปให้ Codex

วิธีนี้ไม่ต้องมี Node.js, npm หรือ Git และเก็บ installation เดิมเป็น backup ก่อนสลับไฟล์

ถ้าเครื่องมี Node.js และติดตั้งผ่าน Skills CLI สามารถลอง:

npx.cmd --yes skills@latest update pasadu --global --yes

หลังรันต้องอ่าน output และตรวจไฟล์จริง เพราะ exit code 0 ไม่ได้แปลว่า Skills CLI พบ installation เสมอ

ถอนการติดตั้ง

วิธีแนะนำคือเปิด task ใหม่ แล้วคัดลอก uninstall-prompt.txt ไปให้ Codex

Codex จะตรวจว่า root เป็น Pasadu ก่อน แล้ว move ทั้งโฟลเดอร์:

%USERPROFILE%\.agents\skills\pasadu

ออกจาก active skill path ไปเก็บใน:

%USERPROFILE%\.pasadu-backups

วิธีนี้ไม่ต้องมี Node.js, npm หรือ Git และสามารถกู้คืนได้

ถ้าเครื่องมี Node.js และติดตั้งผ่าน Skills CLI สามารถใช้:

npx.cmd --yes skills@latest remove pasadu --global --agent codex --yes

ข้อควรรู้

- Skills CLI ติดตั้งเฉพาะ standalone runtime จาก skills/pasadu ไม่ได้ติดตั้ง repository สำหรับพัฒนา
- อย่าใช้ git pull ภายในโฟลเดอร์ที่ Skills CLI ติดตั้ง
- อย่าลบ backup จาก fallback update จนกว่าจะทดสอบ skill รุ่นใหม่แล้ว
- อย่าแก้ไขหรือลบไฟล์กฎหมายและ index ใน installed skill
- ถ้าคำตอบมีผลต่อสิทธิ หน้าที่ งบประมาณ สัญญา หรือความรับผิด ให้ตรวจต้นฉบับทางการและหน่วยงานผู้มีอำนาจอีกครั้ง
