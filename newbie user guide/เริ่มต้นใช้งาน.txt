เริ่มต้นใช้งาน Pasadu

Pasadu คือผู้ช่วย AI สำหรับให้คำปรึกษางานจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐของไทย

คุณไม่จำเป็นต้องอ่าน INSTALLATION.md เอง
ให้ Codex เป็นผู้เปิดอ่านและดำเนินการติดตั้งตามเอกสารนั้นให้คุณ

สิ่งที่ต้องมี

1. คอมพิวเตอร์ Windows
2. Codex Windows App
3. อินเทอร์เน็ต

ขั้นตอนติดตั้ง

1. เปิด Codex Windows App
2. เปิด task หรือแชทใหม่
3. เปิดไฟล์ prompt.txt ในโฟลเดอร์นี้
4. คัดลอกข้อความทั้งหมดใน prompt.txt
5. วางข้อความนั้นในแชท Codex แล้วส่ง
6. รอให้ Codex อ่าน INSTALLATION.md และดำเนินการติดตั้งจนเสร็จ

Codex จะติดตั้ง repository ทั้งชุดให้เป็น Pasadu skill ที่เครื่องของคุณ โดยไม่ต้องให้คุณคัดลอกไฟล์กฎหมายหรือสร้างโฟลเดอร์เอง

เมื่อติดตั้งเสร็จ Codex ต้องแจ้งสถานะ:

PASADU_INSTALLED

จากนั้นให้ปิด Codex แล้วเปิดใหม่ และเริ่ม task ใหม่อีกครั้ง เพื่อให้ Codex โหลด skill ที่ติดตั้งเพิ่ม

ทดสอบการใช้งาน

หลังเปิด task ใหม่ ให้ถามได้เลย เช่น:

การจัดซื้อโดยวิธีเฉพาะเจาะจงใช้ได้เมื่อใด กรุณาอ้างอิงกฎหมายจาก repository

โดยทั่วไปไม่ต้องพิมพ์ชื่อ skill และไม่ต้องใส่คำสั่งพิเศษ

ถ้าต้องการเรียกแบบ manual ให้ลอง:

/pasadu มาตรา 56 กล่าวถึงอะไร

ถ้า Codex ไม่รู้จัก /pasadu ให้ใช้:

$pasadu มาตรา 56 กล่าวถึงอะไร

หรือถามเป็นภาษาธรรมชาติตามปกติได้เช่นเดิม

ข้อควรรู้

- อย่าคัดลอกเฉพาะ SKILL.md เพราะ Pasadu ต้องใช้ไฟล์อื่นใน repository ด้วย
- อย่าแก้ไขหรือลบไฟล์กฎหมายและ index ระหว่างติดตั้ง
- ถ้า Codex แจ้งว่าติดตั้งไม่สำเร็จ ให้คัดลอกข้อความผิดพลาดส่งกลับไปในแชทเดิม
- คำตอบด้านกฎหมายที่มีผลต่อสิทธิ หน้าที่ งบประมาณ สัญญา หรือความรับผิด ควรตรวจสอบต้นฉบับทางการและหน่วยงานผู้มีอำนาจอีกครั้ง
